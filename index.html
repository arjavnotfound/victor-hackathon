Find hidden cameras by making them react.

Every hidden camera has a lens, and if it streams, it has to react to what it sees. We test both, using a secret random code that nothing else in the room can fake.

1. Lens scan

Use your Android phone. The torch blinks a secret pattern. Any tiny dot that blinks back in the same pattern is a lens, and gets a circle.

Open lens scan

2. Wi-Fi challenge

The screen flashes a secret pattern at the suspicious object. A camera that streams sends more data when the picture changes. We find the device whose traffic follows the pattern.

Open Wi-Fi challenge

3. Proof you can share

Every test can be saved as a PDF report with the time, the code, the device found, the graphs and a SHA-256 fingerprint. If anyone edits the report, the fingerprint will not match.
